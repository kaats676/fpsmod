# FPS Display Mod for Minecraft 1.16.5

[![Build Status](https://github.com/kaats676/fpsmod/actions/workflows/build.yml/badge.svg)](https://github.com/kaats676/fpsmod/actions/workflows/build.yml)
[![Modrinth](https://img.shields.io/badge/Modrinth-1.16.5-00AF5C?logo=modrinth)](https://modrinth.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A lightweight **Forge** mod for **Minecraft 1.16.5** that displays the current **FPS** (frames per second) in the top‑right corner of the screen.  
The counter automatically hides when you press **F1** (hide GUI).

---

## ✨ Features

- 📊 **Real‑time FPS display** – always up‑to‑date.
- 🎨 **Shadowed text** – readable on any background.
- 🙈 **F1 support** – disappears when you hide the GUI.
- 🧩 **Lightweight** – no configuration, no performance impact.
- 🔧 **Forge 1.16.5** – compatible with all mods that use the standard overlay.

---

## 📥 Installation

1. **Install Minecraft Forge** for 1.16.5 (version **36.2.34** or later).
2. Download the latest `.jar` file from:
   - [GitHub Releases](https://github.com/kaats676/fpsmod/releases)
   - or [Modrinth](https://modrinth.com/) (if published).
3. Place the `.jar` into your `mods` folder.
4. Launch the game.
